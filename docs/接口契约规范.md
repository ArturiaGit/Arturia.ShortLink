## 1. 全局约定与协议规范

### 1.1 基础请求头 (Headers)
* `Content-Type: application/json; charset=utf-8`
* `Authorization: Bearer <jwt_token>`（已登录用户调用所有业务接口时必传）
* `X-Workspace-Id: <workspace_id>`（租户上下文，指定当前操作所属的工作空间 ID）

### 1.2 统一响应结构 (Response Envelope)

所有接口统一以 JSON 格式返回如下结构：

```typescript
interface ApiResponse<T = any> {
  code: number;      // 业务状态码：200 表示成功，非 200 表示业务异常
  success: boolean;  // 业务是否处理成功
  message: string;   // 提示信息（如 "操作成功"、"短码已被占用"）
  data: T;           // 具体的业务数据负载
}
```

### 1.3 分页统一响应结构 (Page Result)

```typescript
interface PageResult<T> {
  items: T[];
  total: number;
  page: number;
  pageSize: number;
  totalPages: number;
}
```

### 2.1 用户登录

## 5. 短链核心模块 (Links)

### 5.1 分页查询短链列表
* **路径**: `GET /api/v1/links`
* **Query 参数**:
  * `page`: 当前页码（从 1 开始，默认 1）
  * `pageSize`: 每页条数（默认 10）
  * `search`: 关键词搜索（匹配别名 slug / 标题 / 原始 URL）
  * `domainId`: 域名过滤（可选）
  * `isActive`: 启用状态过滤（可选，true / false）
* **响应 `data`**: `PageResult<ShortLinkItem>`
```json
{
  "items": [
    {
      "id": "1",
      "workspaceId": "1",
      "domain": "art.link",
      "slug": "github-repo",
      "shortUrl": "https://art.link/github-repo",
      "originalUrl": "https://github.com/dotnet/aspnetcore",
      "title": "ASP.NET Core 官方主页",
      "description": "微软官方开源高性能 Web 框架仓库",
      "isActive": true,
      "hasPassword": false,
      "expiresAt": null,
      "totalClicks": 3482,
      "totalUniqueVisitors": 2190,
      "utmSource": "newsletter",
      "utmMedium": "banner",
      "utmCampaign": "dotnet10_launch",
      "createdById": "1",
      "creatorName": "Arturia Admin",
      "creatorAvatar": "https://images.unsplash.com/...",
      "createdAt": "2026-09-01T12:00:00Z"
    }
  ],
  "total": 1,
  "page": 1,
  "pageSize": 10,
  "totalPages": 1
}
```

### 5.2 创建短链
* **路径**: `POST /api/v1/links`
* **说明**: 服务端自动从请求头 `Authorization` 解析当前用户，并将 `created_by` 强绑定为当前用户 ID。
* **请求体**:
```json
{
  "originalUrl": "https://dotnet.microsoft.com/download/dotnet/10.0",
  "domainId": "1",
  "slug": "dotnet10",             // 可选；若未提供则系统自动生成 6 位 Base62 字符
  "title": ".NET 10 正式版下载",   // 可选；链接别称
  "description": "最新运行时下载页面",
  "password": "",                 // 可选；访问保护密码
  "expiresAt": null,              // 可选；ISO 8601 时间戳
  "utmSource": "wechat",          // 可选
  "utmMedium": "social",          // 可选
  "utmCampaign": "dotnet10_rc",   // 可选
  "utmTerm": "",
  "utmContent": ""
}
```

### 5.3 更新短链
* **路径**: `PUT /api/v1/links/{id}`
* **权限规则 (RBAC)**：空间 `owner` 与 `admin` 可修改空间内全部短链；`member` 仅可修改本人创建的短链，越权操作返回 403 Forbidden (`{ "code": 403, "success": false, "message": "无权限：业务协作者仅可修改本人创建的短链" }`)。
* **请求体**: 字段与创建一致（支持修改原始目标 URL、别名、有效期与密码等）。

### 5.4 快速切换短链启停状态
* **路径**: `PATCH /api/v1/links/{id}/status`
* **权限规则 (RBAC)**：空间 `owner` 与 `admin` 可启停全部短链；`member` 仅可启停本人创建的短链，越权操作返回 403 Forbidden。
* **请求体**:
```json
{
  "isActive": false
}
```

### 5.5 删除短链
* **路径**: `DELETE /api/v1/links/{id}`
* **权限规则 (RBAC)**：空间 `owner` 与 `admin` 可删除全部短链；`member` 仅可删除本人创建的短链，越权操作返回 403 Forbidden。

## 8. 公网短链重定向引擎 (Public Redirect Engine)

### 8.1 短链跳转接口
* **路径**: `GET /{slug}`
* **业务逻辑说明**:
  1. 根据请求的 `Host` 头获取域名，结合 `slug` 在数据库/缓存中精确匹配短链记录。
  2. 校验 `is_active` 是否为 1 以及 `expires_at` 是否已超时。
  3. 若短链设置了访问密码，先展示前端密码输入卡片进行验证。
  4. 采集访问日志（IP、User-Agent、Referer、GeoIP 国家省市解析），异步入库。
  5. 拼接 UTM 参数后，向访客返回 **302 Found** 临时重定向响应。
