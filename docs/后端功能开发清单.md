>    * 后端 Agent 必须严格以本清单和《后端详细设计与技术实现说明书.md》为实现标准；

>    * 每完成一个大阶段全部开发并自测通过后，在本文档中将对应子任务项由 `[ ]` 勾选为 `[x]`。
> 3. **架构与工程底线 (Clean Architecture & Non-Negotiable Rules)**：
>    * 严格采用标准 Clean Architecture 4 层工程结构（`Arturia.ShortLink.Domain` / `Application` / `Infrastructure` / `Api`）；
>    * 数据库实体映射严格对齐 `docs/数据库设计.sql`，采用 EF Core Code-First Fluent API 配置，支持应用启动时自动执行迁移与种子数据填充；
>    * 数据安全：实体统一实现 `IWorkspaceScopedEntity`，通过 EF Core `HasQueryFilter` 全局注入租户物理隔离；
>    * 高并发与轻量化：短链跳转通过 `System.Threading.Channels` 进程内异步削峰与 IP+UA 字典去重计算 UV，不强依赖外部 Redis，后台 HostedService 批量回写 MySQL；
>    * 鉴权：实现双模 Bearer 鉴权，无缝支持 JWT 与 `art_live_` API Key。
> 4. **人机协同大阶段交付与验收门禁 (Human-in-the-Loop Workflow)**：
>    * 严格以**后端大阶段（Phase）**为进度推进单元，严禁跨阶段混合交付；
>    * 每阶段完成前必须自检：`dotnet build` 确保 0 报错 0 警告，运行自动化测试确保全部 Pass；

## 后端阶段四：公网极速 302 重定向与 Channels 进程内削峰消费

- [ ] **4.1 公网短链极速重定向路由 (`GET /{slug}`)**
  - [ ] 识别请求 `Host` 域名与 `slug`，从数据库高效检索短链（使用 `.IgnoreQueryFilters()` 绕过多租户过滤）。

    - [ ] 检查 `is_active` 是否为 1（若为 0，302 跳转至前端暂停提示页或返回对应友好页面）。
    - [ ] 检查 `expires_at` 是否已过期（若已过期，302 跳转至前端过期提示页）。
- [ ] **4.2 密码保护短链流转与解锁接口**
  - [ ] 若短链配置了密码：
    - [ ] 检查请求是否携带有效放行 Cookie：`art_pwd_ticket_{slug}`。
    - [ ] 若无有效 Cookie，直接 302 重定向至前端 SPA 密码解锁卡片：`https://{Host}/unlock/{slug}`。
  - [ ] 实现 `POST /api/v1/links/{slug}/unlock` 密码校验接口：
    - [ ] 请求体：`{ "password": "..." }`。
    - [ ] 校验密码哈希是否匹配；若成功，生成包含 slug 的短期 HMAC 签名票据，并在 Response Header 中设置 `Set-Cookie: art_pwd_ticket_{slug}=...; Max-Age=1800; HttpOnly; SameSite=Lax`。
    - [ ] 返回 `{ code: 200, success: true, data: { originalUrl: "...", ticket: "..." } }`。
- [ ] **4.3 非阻塞日志投递与 System.Threading.Channels 缓冲**
  - [ ] 定义 `ClickLogEvent` 数据载荷（短链ID、空间ID、IP、UA、Referer、时间戳）。
  - [ ] 初始化单例 `Channel<ClickLogEvent>`（设置容量上限与背压缓冲）。
  - [ ] 重定向方法在下发 302 前，调用 `Channel.Writer.TryWrite(event)` 非阻塞投递事件，端到端延迟控制在毫秒级。
- [ ] **4.4 内存 IP+UA 字典去重与后台 HostedService 批量落盘**
  - [ ] 实现后台消费服务 `LogConsumerHostedService : BackgroundService`。
  - [ ] 进程内维护 `ConcurrentDictionary<string, byte>` 或 LRU 内存缓存记录当日唯一键 `uv:{linkId}:{date}:{MD5(ip+ua)}`。
  - [ ] 缓冲池满足 500 条日志或 2 秒超时，自动触发一次批量写入：
    - [ ] 批量 `INSERT INTO link_access_log`。
    - [ ] 批量累加对应短链的 `total_clicks`（PV）与 `total_unique_visitors`（当日新访客 UV）。
