# Arturia.ShortLink - 后端功能开发 TODO 清单 (Backend Agent 唯一执行基准)

> ### 🛑 铁律与多 Agent 协同边界 (Strict Boundaries & Multi-Agent Sync)
> 1. **专职边界 (Backend Agent Only)**：
>    * **后端 Agent（独立会话）职责**：**100% 负责后端工程**。基于 `docs/后端详细设计与技术实现说明书.md`、`docs/接口契约规范.md` 与 `docs/数据库设计.sql`，独立构建现代标准 .NET 10 + C# ASP.NET Core WebAPI + MySQL 8.0.46 后端工程。
>    * **前端 Agent（前端会话）职责**：负责前端 React 19 + shadcn/ui + Mock 页面，已由前端 Agent 独立闭环完成前置功能。
> 2. **跨 Agent 双向文档同步协议 (Cross-Agent Sync Protocol)**：
>    * 后端 Agent 必须严格以本清单和《后端详细设计与技术实现说明书.md》为实现标准；
>    * 若在实际开发与接口落地中有任何字段微调、契约完善或枚举补充，**必须同步在同一次提交中更新《接口契约规范.md》与《后端详细设计与技术实现说明书.md》文首的修订流水**；
>    * 每完成一个大阶段全部开发并自测通过后先等待人工验收；仅在用户明确批准后，才在特性分支将对应子任务由 `[ ]` 勾选为 `[x]`、更新本清单修订记录并复跑门禁。
> 3. **架构与工程底线 (Clean Architecture & Non-Negotiable Rules)**：
>    * 严格采用标准 Clean Architecture 4 层工程结构（`Arturia.ShortLink.Domain` / `Application` / `Infrastructure` / `Api`）；
>    * 数据库实体映射严格对齐 `docs/数据库设计.sql`，采用 EF Core Code-First Fluent API 配置，支持应用启动时自动执行迁移与种子数据填充；
>    * 数据安全：实体统一实现 `IWorkspaceScopedEntity`，通过 EF Core `HasQueryFilter` 全局注入租户物理隔离；
>    * 高并发与轻量化：短链跳转通过 `System.Threading.Channels` 进程内异步削峰与 IP+UA 字典去重计算 UV，MVP 不依赖 Redis，后台 HostedService 批量回写 MySQL；
>    * 鉴权：实现双模 Bearer 鉴权，无缝支持 JWT 与 `art_live_` API Key。
> 4. **人机协同大阶段交付与验收门禁 (Human-in-the-Loop Workflow)**：
>    * 严格以**后端大阶段（Phase）**为进度推进单元，严禁跨阶段混合交付；
>    * 每阶段完成前必须自检：`dotnet build` 确保 0 报错 0 警告，运行自动化测试确保全部 Pass；
>    * **自动唤起审阅与质量门禁**：确保 `dotnet test` 测试 100% 通过，启动 Kestrel 服务并通过系统命令（`Start-Process "http://localhost:5000/scalar/v1"` 或 `/swagger`）**主动在用户默认浏览器中打开交互式 API 文档**供人工审阅体验；
>    * **审阅确认后自动 PR 合并闭环**：**在获得用户明确同意前绝对严禁 git commit 或 git push**；用户确认同意后，Agent 先在特性分支勾选清单并复跑门禁，再规范提交、推送到远端特性分支（`feat/phase-X-<name>`），通过 `gh pr create` 发起 Pull Request、调用 `gh pr merge --squash --delete-branch` 合并并切回 main 同步，随后**立即原地暂停**，等待下一阶段指令。

- [ ] **4.2 密码保护短链流转与解锁接口**
  - [ ] 若短链配置了密码：
    - [ ] 检查请求是否携带有效放行 Cookie：`art_pwd_ticket_{slug}`。

  - [ ] 实现 `POST /api/v1/links/{slug}/unlock` 密码校验接口：
    - [ ] 请求体：`{ "password": "..." }`。
    - [ ] 校验密码哈希是否匹配；若成功，生成包含 slug 的短期 HMAC 签名票据，并在 Response Header 中设置 `Set-Cookie: art_pwd_ticket_{slug}=...; Max-Age=1800; HttpOnly; SameSite=Lax`。
    - [ ] 返回 `{ code: 200, success: true, data: { originalUrl: "...", ticket: "..." } }`。
- [ ] **4.3 非阻塞日志投递与 System.Threading.Channels 缓冲**

  - [ ] 缓冲池满足 500 条日志或 2 秒超时，自动触发一次批量写入：
