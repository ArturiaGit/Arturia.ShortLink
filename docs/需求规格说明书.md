### 1.1 项目背景
短链（URL Shortener）作为数字营销、社交媒体分发、短信营销、广告归因及企业级资产管理的核心基础设施，承载着“缩短链接字符、美化视觉展示、精准追踪数据、动态智能分流”等多重使命。
本项目旨在打造一套高可用、可商用的**多租户短链 SaaS 平台**（对标 Dub.co 与 Bitly），提供卓越的用户体验、精细化的营销归因分析、企业级团队空间隔离以及高性能的公网跳转服务。

### 1.2 产品定位
* **产品形态**：商业化多租户短链 SaaS 平台。
* **交付模式**：
  * **前端**：现代化 React Web 端（基于 Tailwind CSS + shadcn/ui + Lucide Icons + Recharts，开箱支持高保真交互与 Mock 模式）。
  * **后端**：.NET 10 + C# WebAPI + MySQL（初期专注单体高并发与数据完整性，架构预留 Redis 缓存与 RabbitMQ 异步日志接入）。
* **核心价值主张**：
  * **品牌归属感**：支持绑定企业自定义独立域名（如 `go.mybrand.com/sale`），强化企业品牌认知。
  * **精细化归因**：内置 UTM 构建器与深度多维访问数据看板（PV/UV、渠道、地域、终端）。
  * **营销与安全**：动态二维码定制、密码保护、访问有效期及三层风控拦截。
  * **团队协作**：工作空间（Workspace）多租户隔离与三级 RBAC 权限矩阵。

## 2. 用户角色与权限模型 (RBAC)

平台采用租户（工作空间）级隔离机制。同一用户账号可以加入多个工作空间，并在不同空间内拥有独立的权限身份。

### 2.1 角色定义
1. **空间所有者 (Owner)**：工作空间的创建者，拥有该工作空间的最高支配权，全局唯一或可显式转让。
2. **团队管理员 (Admin)**：空间日常运营与技术管理员，负责域名配置、成员出入与全部短链资产管控。
3. **业务协作者 (Member)**：市场营销人员、业务开发人员，专注短链创建、编辑管理及数据报表查阅。

### 2.2 权限控制矩阵

| 业务功能模块 | 空间所有者 (Owner) | 团队管理员 (Admin) | 业务协作者 (Member) |
| :--- | :---: | :---: | :---: |

| **工作空间注销 / 所有权转让** | ✅ 允许 | ❌ 禁止 | ❌ 禁止 |

## 3. 核心功能需求详细规范

### 3.1 工作空间与租户隔离 (Workspace)
* **需求描述**：提供多租户逻辑隔离机制，不同工作空间的数据（短链、域名、访问日志、成员、API Key）严格隔离。
* **业务规则**：
  1. 用户登录后，系统默认进入其上次活跃的工作空间。
  2. 顶部导航栏常驻“工作空间切换器”，支持快速搜索和一键切换。
  3. 支持创建新工作空间（需填写空间名称与唯一标识 Slug）。
  4. 支持通过邮箱邀请团队成员，受邀人登录后即可协同操作。

### 3.2 独立域名与品牌定制 (Custom Domains)
* **需求描述**：支持企业租户接入自有独立二级域名，替代公共短链域名，提升点击率与信任度。
* **业务规则**：
  1. **系统默认域名**：平台预置系统共享域名（如 `art.link`），所有租户开箱即用。
  2. **自定义域名绑定**：
     * 租户可添加自有二级域名（如 `link.mybrand.com`）。
     * 系统生成对应的 DNS CNAME 指向目标与 TXT 校验码。
     * 用户配置 DNS 解析后，点击“立即验证”，系统发起 DNS 查询。校验通过后，域名状态置为“已激活”。
  3. **域名短码作用域隔离**：
     * **短码作用域为域名级别唯一**（即 `art.link/sale` 与 `link.mybrand.com/sale` 互不冲突）。
     * 极大释放常用优质别名（如 `/login`, `/app`, `/pricing`），各租户拥有专属命名空间。

### 3.3 短链生命周期与创建引擎 (Link Engine)
* **需求描述**：提供高效、灵活的长链接缩短与管理能力。
* **业务规则**：
  1. **独立生成模式**：
     * 遵循“同一长链接可多次缩短”原则。同一目标 URL 可被重复创建为多条独立短链，分别赋予不同的 UTM 参数、别名或标签，便于多渠道投放与效果拆解对比。
  2. **短码（Slug）生成规则**：
     * **自动生成**：若用户未填写别名，系统自动生成 **6 位 Base62** 字符短码（包含大小写字母与数字 `0-9, a-z, A-Z`，具备 568 亿种独立组合空间）。
     * **自定义别名**：用户可手动指定个性化别名（长度 3~32 位，支持字母、数字、短横线 `-` 与下划线 `_`）。
     * **唯一性校验**：同一域名下别名冲突时，系统即时拦截并给出明确提示。
  3. **短链管理操作**：
     * **启停开关**：支持随时一键切换“启用/禁用”状态；禁用状态下短链跳转直接拦截并显示友好提示页。
     * **目标修改**：支持在不改变短码的前提下，随时动态修改原始目标长链接（解决物料印刷后目标地址变更的痛点）。
     * **软删除**：删除短链后短码释放，历史数据安全归档。
  4. **创建者绑定与归属审计 (Creator Binding & Attribution)**：
     * 每一条短链必须强制关联创建人用户账号（`created_by`），并在数据层建立查询索引。
     * 控制台短链列表中显式呈现创建人标识（`[ 👤 创建人姓名 ]`），增强多成员团队的协同透明度。
     * 结合第 2.2 节 RBAC 权限矩阵：业务协作者 (Member) 仅具备本人创建短链的修改、启停与删除权，若尝试操作他人短链则在界面与接口双层实施阻断拦截。

### 3.4 营销增强工具箱 (Marketing Suite)
* **需求描述**：为运营与营销团队提供一站式流量获取与分发增强工具。
* **业务规则**：
  1. **动态二维码（QR Code）**：
     * 每一条短链自动配套生成高保真动态二维码。
     * 支持前端实时调节前景色、背景色、容错率（L/M/Q/H）。
     * 支持上传并嵌入中心品牌 Logo 图标。
     * 支持一键下载导出高清 **PNG**（适合屏幕分发）及 **SVG**（矢量无损，适合线下物料印刷）。
  2. **交互式 UTM 营销参数构建器**：
     * 创建/编辑短链时提供可视化的 UTM 拼装工具，支持输入 `utm_source`（广告来源）、`utm_medium`（媒介形式）、`utm_campaign`（活动名称）、`utm_term`（搜索词）、`utm_content`（内容标识）。
     * 实时在界面预览拼装后的完整长链接。
  3. **访问密码保护 (Password Protection)**：
     * 支持为敏感或内部短链设定访问密码（基于安全哈希存储）。
     * 访客点击短链时展示极简密码验证卡片，验证通过后方可放行重定向。
  4. **链接有效期控制 (TTL / Expiration)**：
     * 支持设定精确到分钟的过期时间。
     * 到期后链接自动失效，访问时展示“链接已过期”提示界面。

### 3.5 深度数据分析与指标统计 (Analytics & Insights)
* **需求描述**：提供实时、多维度的访问分析报表，帮助运营人员透视流量构成与投放 ROI。
* **业务规则与指标口径**：
  1. **PV（页面点击总量）**：每一次成功的短链重定向请求均计入 1 次 PV。
  2. **UV（独立访客数量）**：
     * 采用 **`访客公网 IP + User-Agent 哈希`** 组合算法计算当日独立访客。
     * 纯服务端高性能运算，302 跳转零额外延迟，兼顾局域网多设备区分与数据真实性。
  3. **爬虫与机器人过滤 (Bot Filtering)**：
     * 系统内置常见网络爬虫识别库（覆盖 Googlebot, Baiduspider, Bingbot, 微信网页预览机器人等）。
     * 自动标记并过滤抓取探测流量，确保商业报表数据纯净。
  4. **报表核心维度**：
     * **时序趋势图**：支持查看近 24 小时、近 7 天、近 30 天的 PV 与 UV 走势折线图。
     * **地理位置透视**：基于访客 IP 解析国家、省市分布，提供排行榜与占比。
     * **终端环境分布**：操作系统（Windows/macOS/iOS/Android）、浏览器（Chrome/Safari/Edge/WeChat）、设备类型（Desktop/Mobile/Tablet）环形图。
     * **来源渠道排行 (Referrer)**：统计访客来源站点（如直接访问、知乎、微信、小红书、微博、GitHub 等）。
     * **UTM 归因透视**：按不同 Campaign/Source 汇总各活动引流成效。
  5. **数据导出**：
     * 支持将短链列表、单链访问趋势与明细报表一键导出为 **CSV** 格式文件，便于运营人员离线复盘与制作汇报。

### 3.6 公网访客跳转端终端体验 (Public Redirect Engine)
* **需求描述**：处理外部真实访客点击短链时的底层重定向与边界交互。
* **业务规则**：
  1. **极速 302/307 临时重定向**：
     * 正常状态下的有效短链，在完成访问日志采集后，直接返回 HTTP 302/307 状态码跳转至目标长链接，端到端延迟控制在毫秒级。
     * 严禁使用 301 永久重定向（防止被客户端浏览器持久缓存导致后续统计失效及目标更新无法生效）。
  2. **密码拦截卡片**：
     * 遇到密码保护链接，展示极简美观的“请输入访问密码”交互界面。
     * 输入正确后下发短期临时放行凭证，跳转至目标长链。
  3. **异常与友好提示页**：
     * **链接已停用**：展示“该链接已被创建者暂停访问”友好插画与提示。
     * **链接已过期**：展示“该链接已于 [过期时间] 到期失效”。
     * **链接被封禁**：展示“该链接因涉嫌违规/安全风险已被系统冻结”。
     * **短码不存在 (404)**：展示“未找到该短链，请核对后重试”。

### 3.7 开放平台与开发者 API (Developer Platform)
* **需求描述**：支持企业通过程序自动化批量缩短链接、集成至内部 CMS/ERP/营销机器人。
* **业务规则**：
  1. 租户管理员可在控制台创建独立 API Key。
  2. 生成时系统仅展示一次完整密钥明文，数据库中仅存储 SHA256 哈希值与前缀识别码（如 `art_live_...`）。
  3. 开发者在 HTTP 请求头中携带 `Authorization: Bearer <API_KEY>` 即可免 Cookie 调用短链全生命周期开放接口。
  4. 支持随时吊销或重新生成 API Key。

## 4. 安全风控与防滥用规范 (Security & Compliance)

为了防止短链服务沦为恶意钓鱼、垃圾广告及病毒分发的跳板，保障服务域名信誉安全，确立**三层实用型安全风控机制**：

1. **第一层：协议严格白名单与防自环机制**
   * 仅允许 `http://` 与 `https://` 协议，严禁 `javascript:`、`data:`、`file:`、`vbscript:` 等恶意伪协议。
   * **严格防自环递归**：禁止将短链域名自身作为目标长链接（例如在 `art.link` 平台下禁止缩短 `https://art.link/*`），防止恶意循环重定向造成服务器雪崩或浏览器死锁。
2. **第二层：敏感词与违规域名黑名单拦截**
   * 系统内置可动态更新的违规域名与风险关键词黑名单。
   * 创建/更新短链时执行黑名单快速正则匹配，命中违规域名直接阻断创建并提示警告。
3. **第三层：频次限制与违规一键封禁 (Rate Limiting & Takedown)**
   * **API 限流**：公共跳转接口与短链创建接口限制单 IP 每分钟请求上限，防范恶意爬虫刷量与短码碰撞扫描。
   * **一键封禁与全局阻断**：后台支持将任一短链快速置为“已封禁 (Banned)”状态。一旦封禁，任何访客访问均强制展示安全阻断页，停止向目标网址跳转。

## 5. 非功能性质量需求 (NFR)

1. **重定向性能要求**：
   * 在基础数据库负载下，公网短链 302 跳转响应时间 P95 < 30ms。
   * 架构设计解耦重定向核心逻辑与访问日志存储，日志写入不阻塞页面跳转流程。
2. **数据可用性与安全性**：
   * 密码等敏感字段严格使用不可逆哈希算法（BCrypt / Argon2 / SHA256）存储。
   * 全站传输采用 HTTPS 加密，自定义域名支持 SSL 状态监测。
3. **界面易用性与一致性**：
   * 遵循 shadcn/ui 极简现代设计规范，响应式兼容桌面端（宽屏）与移动端（小屏查阅）。
   * 前端内置交互式 Mock 模式，支持免后端独立演示与全功能测试。

## 6. 产品迭代演进路线 (Roadmap)

* **Phase 1（本次首期 MVP）**：
  * 完成多租户工作空间、Owner/Admin/Member 三级 RBAC。
  * 基础短链引擎、自定义域名绑定、6位 Base62、自定义别名。
  * 营销套件（动态二维码 + 颜色/Logo/下载、UTM 构建器、密码、有效期）。
  * 深度数据分析（PV/UV、IP+UA 统计、爬虫过滤、时序图、地域/终端/渠道分析、CSV 导出）。
  * 开放平台 API Key 管理。
  * 三层基础安全风控与极速 302 跳转体验。
* **Phase 2（第二期演进规划）**：
  * **智能条件分流**：根据访客操作系统（iOS / Android）分流至对应应用商店，根据访客地理位置分流。
  * **大规模批量处理**：支持 Excel/CSV 文件批量导入批量生成短链与二维码打包下载。
  * **基础设施性能跃迁**：引入 Redis 缓存高频短链元数据、引入 RabbitMQ 异步消费海量访问日志、日志持久化迁移至 ClickHouse 分析型数仓。
  * **Webhook 外部事件总线**：短链被点击时实时向第三方企业系统推送 Webhook 通知。
